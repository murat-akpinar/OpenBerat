Why would this be allowed?

The verdict below is policy::decide's own — the same function the proxy runs — over the entitlement rows it would walk. It reads the table, while the proxy may still be answering from a cached decision, so for up to 30 seconds after a rule change this page is right and the live URL is stale.

The record
